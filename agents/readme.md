# agents

Shared agent definitions for the core-superpowers plugin.

10 project-agnostic agents covering workflow orchestration, code review, security auditing, testing strategy, debugging, design pattern guidance, the two spec-driven-development reviewers (`spec-challenger` for adversarial substantive review, `spec-validator` for deterministic structural validation), and the `grafana-engineer` (Grafana / Prometheus / Loki / OpenTelemetry observability work — dashboards, PromQL/LogQL, alerts, OTel pipelines, log ingestion).

See the root [CLAUDE.md](../CLAUDE.md) for authoring conventions.
