# skills

Shared skill definitions for the core-superpowers plugin.

18 workflow skills covering the full development lifecycle: brainstorming, spec-driven development, planning, TDD, execution, debugging, code review, verification, branch completion, merge requests, review resolution, JIRA integration, agent orchestration, and skill authoring.

Each skill is a directory containing at minimum a `SKILL.md` file. See the root [CLAUDE.md](../CLAUDE.md) for authoring conventions.

`spec-driven-development/` is the rigid multi-phase SDD pipeline (constitution → defaults → specify → clarify → plan → tasks → challenge → validate). See its `SKILL.md` for the workflow and the supporting templates, prompts, and references that ship with it.
